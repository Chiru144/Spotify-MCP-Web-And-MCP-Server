Dual-Execution Paradigm: Web UI vs. MCP Agent

Unified Python Backend (FastMCP + FastAPI)

🌐 Mode 1: Interactive Web Studio

  • → Visual Interface: Run at http://127.0.0.1:8000. Users explore filmographies, audition song previews, and tweak audio sliders.
  • → Send Box (Staging Crate): A local staging area to collect songs from multiple movies/artists before batch-exporting to Spotify.
  • → REST Endpoints: Communicates via FastAPI endpoints (e.g. /api/recommendations, /api/playlist/shuffle).

🤖 Mode 2: MCP AI Agent (Claude, Cursor, Cline)

  • → Natural Language: Users talk directly to the agent (e.g., "Make a dark energetic synthwave mix").
  • → Autonomous Reasoning: The LLM translates user vibe adjectives into numerical Spotify parameters (energy, valence, tempo).
  • → Tool Chaining: Agent chains tools seamlessly: searches TMDB $\rightarrow$ gets audio features $\rightarrow$ creates playlist $\rightarrow$ adds tracks.

Vibe & Mood Recommendations

get_recommendations / POST /api/recommendations
MCP Tool Web Modal POST API

Generates a targeted set of tracks using Spotify's multi-seed recommender algorithm. Accepts up to 5 combined seeds (genres, track IDs, artist IDs) along with precise target audio characteristics (energy, valence, danceability, acousticness, tempo BPM).

🌐 In the Web UI

Click the ✨ Vibe button in the top control bar to open the modal dialog. Enter comma-separated seed genres/tracks and tweak the audio sliders.

Submitting sends a payload to /api/recommendations and renders matching songs directly into the studio grid for previewing and staging.

🤖 In the AI Agent

The agent translates text prompts like "Give me uplifting dance music like Dua Lipa" into parameters:

get_recommendations(seed_genres=["pop"], target_valence=0.85, target_danceability=0.8)
Source File: tools/taste.py:132 Supports: 5 seeds max (tracks/artists/genres) + 6 audio targets

Movie Soundtrack Search

search_movie_soundtracks(movie_title, limit)
MCP Tool Web Search

Cross-references The Movie Database (TMDB) with Spotify's catalog. Retrieves official movie metadata, release year, poster art, and pulls official OST and score albums with complete song tracklists.

🌐 In the Web UI

Select 🎬 Movies tab on the home screen, type any movie title (e.g. Interstellar, Inception), and hit Explore. Click any movie card to instantly expand its soundtrack tracks into your crate.

🤖 In the AI Agent

Say: "Find the soundtrack tracks for Oppenheimer". The agent calls this tool to retrieve songs, album URIs, and Spotify links.

search_movie_soundtracks(movie_title="Oppenheimer", limit=20)

Send Box (Staging Crate)

create_playlist + add_songs_to_playlist
Web Feature MCP Batch

A persistent staging crate where users collect individual tracks across movies, singers, and vibe recommendations. Once staged, users can export the crate into a brand new Spotify playlist or append into an existing one with one click.

🌐 In the Web UI

Click + Send on any track card to stage it into the right-hand Send Box sidebar. Give your playlist a title and click Create Playlist to push directly into your Spotify account.

🤖 In the AI Agent

The agent performs equivalent batch staging automatically when you ask: "Create a playlist called Cyberpunk Night and add these 10 tracks."

create_playlist(name="Cyberpunk Night", description="Curated via MCP")

Playlist Shuffler

shuffle_playlist_tool / POST /api/playlist/shuffle
MCP Tool Advanced Tools

Randomizes track order in a playlist using cryptographic-grade random shuffling. Offers two execution modes: Create New Shuffled Playlist (non-destructive) or In-Place Reorder (for playlists you own).

🌐 In the Web UI

Navigate to /tools (Advanced Tools), pick a playlist from the dropdown or paste a link, and choose whether to create a new playlist or shuffle in-place.

🤖 In the AI Agent

Prompt: "Shuffle my Chill Vibes playlist into a new playlist." The agent handles the track retrieval, random permutation, and playlist generation.

shuffle_playlist_tool(playlist_id="spotify:playlist:...", in_place=False)
